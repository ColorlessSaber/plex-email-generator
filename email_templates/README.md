# Email Templates Folder
This folder contains the templates/go-bys for the different emails that the tool can generate.
<br>
<br>
The individual HTML email templates have similar structure to each other. This was done on purpose to make it so
each HTML email could use the same code.
<br>
A TV show's seasons that are on the Plex server will be shown on the movie & TV show template.
Example: Castle Season 1-5.
<br>
When a new season is added to an existing TV show the same template will be used. Example: Frieren Season 2.
<br>
In a similar sense, when a 4K movie or TV show is added to the Plex server it will be stated so with the title.
Example: Alien 4K, Arcane Season 1-2 4K
